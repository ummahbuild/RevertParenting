# Agent Harness — RevertParenting

## Mission
Build a privacy-first, family-centered Islamic education platform that pairs parent learning with child guidance and offline family practice.

## Mandatory skills
Read skills/README.md and apply relevant specialist skills before writing parenting, Qur'an, Sunnah or curriculum material. Read docs/EVIDENCE.md for all religious claims.

## Rules
- Never fabricate Qur'an, hadith, scholarly consensus or citations.
- Separate source text, interpretation, parenting science and practical advice.
- All religious content is draft until reviewed by a qualified human.
- No unrestricted AI chat for children; no child religious-worth scoring.
- No physical punishment instructions or coercive conversion scripts.
- Protect minors, household data and family conflict information.
- Code: TypeScript, explicit validation, accessible interfaces, RLS, unit and integration tests.
- Update documentation and acceptance criteria with every feature.
- Do not claim builds, tests, source audits or approvals that did not occur.

## PR checklist
Feature scope; UX states; tests; accessibility; data privacy; source provenance; scholarly and safeguarding approval where relevant; localization; rollback.

## Priority
P0: onboarding, family roles, parent academy, dual-learning lessons, source registry, safe guidance, editorial review. P1: mosque/mentor referrals, multilingual audio, printables, school support.
