# RevertParenting — Engineering Delivery Roadmap

## Principles
Ship a complete parent-child learning journey before breadth. All curriculum is draft until source, scholar and safeguarding approval. Never score faith, pressure children or allow unrestricted minor AI chat.

## Phase 0: Foundation and security (2 sprints)
- Audit current Expo/Next.js versions and install dependencies with lockfile.
- Typecheck/build/test web and mobile; fix failures.
- Supabase household creation with guardian roles, read/write RLS, security tests, export/deletion.
- Shared curriculum package used by both clients; remove duplicated preview data.
- Event schema with minimal consent-based analytics.
Exit: reproducible CI, secure test household lifecycle, accessible navigation.

## Phase 1: First family journey (2 sprints)
- Welcome -> optional anonymous preview -> parent confidence -> age bands -> goals -> 7-day plan.
- Parent primer -> child explanation -> shared activity -> private reflection.
- Multiple children with independent learning pace; offline printables.
- Content status enforced server-side; no draft religious instruction published.
Exit: parent can complete and revisit a session on both platforms.

## Phase 2: Content and safety (3 sprints)
- Evidence registry, translation licenses, hadith grading, interpretation review.
- Editorial dashboard with source verification, scholar and safeguarding signoff.
- Ten pilot lessons with complete scripts and activities; qualified review before release.
- Parent-only question guidance with approved-source retrieval and escalation.
Exit: content approval gates tested and expert reviewed.

## Phase 3: Family experiences (3 sprints)
- Today/week planner, audio and accessibility, optional reminders.
- Family conversation library, screen-free activity packs, initial cooperative games.
- Parent journal, household privacy mode, multilingual foundation and RTL.
Exit: closed family beta with monitored safety and research.

## Phase 4: Growth and community (3 sprints)
- SEO learning pages, ethical waitlist, welcome emails, builder portal.
- Mosque partner referral system and vetted adult mentor discovery.
- Research dashboard, correction workflow and partner pilots.
Exit: privacy/safeguarding review, successful deployment and qualified content signoff.

## Dependency order
Authentication/RLS before private household persistence. Approved source registry before religious lesson publication. Safeguarding before mentor interaction. Consent before marketing automation.

## QA matrix
Web desktop/mobile; Expo iOS/Android; offline; low bandwidth; Arabic RTL; screen reader; large text; shared device; multiple guardians; guardian revoked; age bands 0–18; unapproved lesson blocked; source corrected; data deletion.

## Milestone measurement
Build pass rate, RLS authorization coverage, source accuracy, reviewer turnaround, parent confidence, first family activity completion, week-four retention. No religious-worth metrics.
