# Localization and Cultural Context Engine

## Independent language dimensions
Interface locale, parent learning locale, child learning locale, Qur'an translation, Arabic recitation, glossary language, notification language, community language. Do not assume they are identical.

## Suggested pilot languages (research hypotheses)
English, Arabic, Swahili, Urdu, French, Spanish, Indonesian and Hausa. Select launch languages based on parent demand and qualified translation/review capacity.

## Localization tiers
Tier 0: English product shell and source metadata.
Tier 1: translated UI and consent.
Tier 2: fully translated parent primers and child scripts.
Tier 3: reviewed audio, captions, printable materials and local examples.
Tier 4: qualified region-specific scholarly and community referrals.

## Translation record
locale; source_content_id; version; translator; reviewer; rights; glossary; reading_level; approval; date; fallback; cultural_notes.

## Fallback rules
If a translated lesson is not approved, display an explicit notice and offer an approved available language. Never silently machine-translate a religious ruling or present an unreviewed translation as approved.

## Arabic and RTL
Preserve Arabic source separately, bidi isolation for mixed text, diacritics, recitation controls, attributed translations, optional transliteration, readable line lengths and correct numeral handling.

## Cultural context
Local school systems, religious holidays, grandparents, mosque accessibility, prayer environments, languages, family structures, and minority/majority settings. Distinguish cultural practice from Islamic obligation.

## Offline and accessibility
Locale-specific packs, captions, audio transcripts, large text, screen readers, reduced motion, low-data mode and printables. All translated privacy and safety notices must be reviewed.

## Metrics
Approved locale coverage, missing translation rate, comprehension feedback, translator QA defects, RTL accessibility issues and community referral usefulness.
