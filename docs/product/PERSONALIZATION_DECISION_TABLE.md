# Personalization Decision Table

| Signal | Allowed adaptation | Prohibited inference |
|---|---|---|
| Parent chose 'new to salah' | Offer beginner prayer primer | Parent is less devout |
| Child age 3–5 | Short caregiver-led activity | Child is Muslim |
| Teen age band | Dialogue and source literacy | Teen rejects religion |
| Parent language Swahili | Offer approved Swahili lesson or fallback | Parent is Kenyan |
| Prior Christian background | Optional family transition scenario only when requested | Parent retains Christian beliefs |
| Interfaith household | Respectful co-parent scripts | Household conflict exists |
| Single parent | Short flexible activities | Parent lacks support |
| No mosque nearby | Offline and remote learning options | Family is isolated |
| Optional madhhab preference | Show relevant qualified scholarly explanation | All other interpretations are invalid |
| Offline preference | Download approved packs | User has low income |

## Explanation UX
Every recommendation includes 'Why am I seeing this?' and 'Change this recommendation.' Users can disable background-based personalization without losing core curriculum access.

## Privacy and consent
Separate opt-ins for sensitive revert background, learning analytics, mentor matching and marketing. Never combine religious background with advertising audiences.

## Algorithm guardrails
Deterministic, user-chosen signals first; no opaque religious scoring. Recommendation tests must confirm equal core access regardless of prior religion, ethnicity, language or family structure.
