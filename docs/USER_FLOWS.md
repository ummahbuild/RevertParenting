# End-to-End User Flows

## A. New revert with children
Anonymous preview -> optional profile -> choose child's age band -> choose confidence and learning time -> suggested pathway -> parent primer -> child explanation -> offline activity -> private reflection -> next recommendation.

## B. Parent with teenager who disagrees
Parent-only Ask -> identify concern -> listening-first script -> approved evidence -> acknowledge differing perspectives -> optional scholar/educator referral -> private follow-up. No conversion pressure.

## C. Child knows more than parent
Select joint learning -> parent refresher -> child demonstration -> shared reflection -> independent progress. No shaming or reversal of caregiver responsibility.

## D. First mosque visit
Etiquette lesson -> family facilities checklist -> questions for organizers -> optional local referral -> post-visit reflection.

## E. Parent in interfaith household
Choose scenario -> co-parent boundaries -> family discussion script -> religious distinctions -> referral if custody or conflict issue.

## F. Lesson author
Create draft -> attach source IDs -> choose age adaptations -> child-development review -> scholar review -> licensing review -> publish approved version -> re-review on changes.

## G. Guardian data deletion
Authenticated guardian -> see data categories -> request export/delete -> verify permissions -> confirm deletion and retention exceptions -> audit event.

## Global edge cases
Interrupted onboarding, no internet, no account, missing translations, unsupported age band, unreviewed sources, family conflict, unsafe request, guardian permission revoked, mentor removed, migration failure.
