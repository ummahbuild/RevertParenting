# Curriculum Studio and Publishing Requirements

## Editorial roles
Contributor, editor, qualified scholar reviewer, child-development reviewer, safeguarding reviewer, translator, publisher, administrator. Separate drafting from final approval; preserve reviewer conflicts of interest.

## Content entities
Course -> track -> module -> lesson -> parent primer -> age-band variant -> shared activity -> assessment/reflection -> evidence references -> translations -> media assets -> approval history.

## Review pipeline
Idea -> brief -> draft -> evidence verification -> scholar review -> child-development review -> safeguarding review -> translation/license review -> approved -> staged -> published -> monitored -> archived/revised.

## Hard publication gates
No unverified Qur'an quotation; no unattributed translation; no hadith without source and grade where relevant; no unsupported consensus claims; no high-risk parenting content without safeguarding approval; no unauthorized licensed illustrations/audio.

## Review tools
Diff between lesson versions, inline annotations, source provenance, grade and translator fields, reviewer notes, evidence dispute tags, review deadlines, expiry reminders, emergency unpublish, locale-specific overrides, rollback.

## AI drafting
AI may propose outlines and reading levels but must never approve itself. Every generated sentence is considered unreviewed. Retrieval only from approved corpus for public answers.

## Quality checks
Age appropriateness, accessibility, parent knowledge assumptions, religious accuracy, translation accuracy, family diversity, gender assumptions, screen time, real-world feasibility, emotional safety.

## Content metrics
Review turnaround, source verification failures, re-review age, localization coverage, family activity completion, parent feedback, correction response time.
