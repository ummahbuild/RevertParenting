# Product Release Readiness Checklist

## Engineering
[ ] Web build passes
[ ] Expo builds verified on iOS and Android
[ ] Dependency lockfile and reproducible CI
[ ] Household signup and authorization
[ ] Supabase RLS positive/negative tests
[ ] Backups, migrations, rollback, monitoring
[ ] Data export and deletion
[ ] Offline and low-bandwidth QA
[ ] WCAG 2.2 AA target checks
[ ] RTL and translation tests

## Religious and editorial
[ ] Exact primary source verification
[ ] Hadith grading and scholarly context
[ ] Translation licenses
[ ] Scholar review sign-off
[ ] Child-development review
[ ] Safeguarding review
[ ] Unpublish/correction process

## Marketing and community
[ ] Claims review
[ ] Consent-based waitlist
[ ] Privacy policy and terms
[ ] No invented endorsements/testimonials
[ ] Partner vetting
[ ] Moderation and incident procedures
[ ] Research participant consent

## Release blocker
No religious lesson may be presented as approved while scholarly or safeguarding reviews are pending. No child account or mentor messaging features may launch without security and safeguarding verification.
