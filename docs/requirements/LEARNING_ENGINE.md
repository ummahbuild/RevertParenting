# Learning Engine: Deep Functional Requirements

## Knowledge graph
Topic -> prerequisite concept -> parent competency -> child objective -> shared practice -> evidence -> reviewer. A parent can skip any prerequisite; recommendation is advisory.

## Learning modalities
Text, narration, slow recitation playback, printable worksheet, interactive sequencing, parent-led discussion, screen-free activity, captions and transcripts.

## Recommendation logic
Use explicit family preferences, age band, parent confidence, available time, content approval, accessibility and locale. Never infer religious commitment or child belief from engagement.

## Progress model
Separate parent understanding, child activity participation and family routine completion. No faith or piety scores. Allow pause, skip, repeat, mark as not relevant, and private reflections.

## Mastery evidence
Parent self-assessment, optional factual knowledge checks, voluntary teach-back and activity completion. Avoid claims that app engagement measures iman.

## 12 curriculum tracks
Foundations of Islam; Qur'an; authentic Sunnah; Seerah; salah; dua; Ramadan; akhlaq; family ties; school/community; adolescent questions; parent wellbeing.

## Content quality
Each unit must identify a learning objective, age bands, parent primer, verified source manifest, child language, activity, accessibility adaptations, reviewer and version.

## Special paths
Parent learns Arabic alongside child; child knows more than parent; parent has little time; family changes belief/practice; different fiqh traditions; no local mosque; sensory needs; child hesitant to participate.
