# Admin, Operations, and Incident Requirements

## Admin roles
Superadmin, product operator, content editor, scholar reviewer, child-development reviewer, safeguarding reviewer, localization manager, community moderator and support agent.

## Admin frames
Overview, content queue, evidence registry, hadith grading review, lesson editor, translation queue, publishing diff, user support, guardian data requests, mentor verification, moderation, safety incidents, analytics, feature flags, audit logs, incident dashboard.

## Approval controls
Least privilege, two-person approval for sensitive content, immutable version history, emergency unpublish, reviewer assignment, expiring credentials, conflict-of-interest declaration.

## Support
Private ticket intake, clear response SLA, no AI-only resolution of safeguarding incidents, secure data export/deletion, escalation to legal/clinical/religious experts when appropriate.

## Reliability
Monitoring, backups, restore drills, migration rollback, error budgets, feature flags, incident postmortems, staging environments, production checklist and dependency vulnerability scanning.

## Release criteria
CI passing, RLS negative tests, content review gate passing, accessible core flows, privacy and safeguarding audit, incident response readiness, verified legal disclosures.
