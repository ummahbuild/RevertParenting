# Family Lifecycle Requirements — RevertParenting

Status: specification. This document does not represent implemented functionality.

## Lifecycle stages
Discovery -> anonymous exploration -> parent learning assessment -> family configuration -> first shared lesson -> first week -> 30-day journey -> ongoing family rhythms -> advanced learning and community -> pause/restart -> account export/deletion.

## Onboarding branches
1. Parent recently embraced Islam and has not told children.
2. Children know about parent's conversion but do not identify as Muslim.
3. Family embraces Islam together.
4. Parent returns to practice after years away.
5. Interfaith household with differing parental beliefs.
6. Separated or divorced co-parents with custody constraints.
7. Parent has children across multiple age bands.
8. Child attends Islamic school and knows more than parent.
9. Parent needs disability or language accommodations.
10. Parent prefers anonymous learning.

## Personalization inputs
Parent knowledge confidence by topic (not an overall religious grade); child age band; preferred language; family structure (optional); accessibility preferences; goals; available time; school/community setting (optional); consent status. Avoid requiring sensitive conversion histories.

## Family state machine
anonymous_preview -> onboarding_draft -> household_active -> pathway_selected -> lesson_started -> activity_completed -> reflection_optional -> next_plan. Any state supports pause, skip, resume, privacy controls and deletion.

## Notifications
Opt-in only; quiet hours; no religious guilt or shame; local prayer reminders only after explicit opt-in and location consent; notifications must not disclose conversion status on shared devices.

## Guardian permissions
Household creator; guardian; adult collaborator; educator/mentor. No adult outside the household sees child details without granular consent. Children do not need direct accounts for MVP.

## Parent retention
Weekly check-in: What worked? What felt difficult? What question did your child ask? Parent can choose a smaller plan, skip or switch topics without losing history.

## Edge cases
Shared devices; no email; loss of internet; account compromise; two guardians disagree; household separation; child ages into new band; unsafe family situation; source removed after scholarly review; translation unavailable; parent changes school of thought; mentor loses verification.
